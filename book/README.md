# The Book

This tree is the **linear argument** of *I Have No Dopamine, and I Must Function*. It preserves the manuscript's three-part spine while making each chapter-sized node independently navigable.

- **The Machine That Makes Action Possible** — what action selection is, where dopamine enters it, and how the machinery was assembled by evolution.
- **The Illness** — what happens when reward and action systems fail, and why existing diagnostic categories only partially capture that failure.
- **The Atrocity** — what institutions do when biological failures of agency are interpreted as vice, criminality, or noncompliance.

The files below are the current manuscript sources. Side research that is not presently in the linear book lives under [`/dossiers`](../dossiers/README.md).
