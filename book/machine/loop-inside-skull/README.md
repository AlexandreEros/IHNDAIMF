# The Loop Inside the Skull

This node gives the reader the compact anatomy needed for everything that follows: cortico-striato-thalamo-cortical loops, basal ganglia, striatum, prefrontal cortex, thalamus, midbrain dopamine systems, and limbic inputs.

It then connects that machinery to pleasure, motivation, authorship, and the self. The goal is a usable mental model, not a neuroanatomy exam.
