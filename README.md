# I Have No Dopamine, and I Must Function

*A philosophical-neuroscientific-sociological manifesto about agency, reward, and what happens when failures of action are treated as failures of character.*

This branch is a **GitBook pilot** built directly on the manuscript's native Markdown corpus. The existing LaTeX book remains intact as a print projection; the Markdown files are used here as navigable web pages rather than being flattened into one enormous linear document.

## How to use this edition

There are two sensible ways in.

- **Read the argument.** Follow Parts I–III in the sidebar: the machinery of action, the illness, and the institutional consequences.
- **Use it as a reference.** Search for a concept you have forgotten and jump directly to the relevant dossier. The point is specifically *not* to require somebody to reread hundreds of pages of lamprey scholarship to remember what a D2 receptor is doing in the argument.

The long-term architecture can support a third route as well: stable concept pages and formal claims that link back to the evidence-bearing dossiers. That layer is intentionally not fabricated in this first pilot.

## Epistemic register

The manuscript moves among four different kinds of statement and should not silently collapse them into one another:

1. **Established neuroscience** — claims intended to rest on well-supported empirical literature.
2. **Reasonable synthesis** — arguments connecting neurobiology to agency, moral judgment, clinical framing, or institutions.
3. **Speculative phenomenology** — attempts to describe the interior structure of severe reward deprivation and failures of authorship.
4. **Rhetorical / literary image** — deliberate metaphors, satire, and engineered disruptions that carry argumentative or mnemonic force without pretending to be experimental results.

The goal of this web edition is to make those distinctions *easier* to inspect, not to sand the manuscript into polite academic mush.
